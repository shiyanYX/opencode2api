方向 C · 表格优先 原型工具 · 不进生产实现 表格状态 节点层告警 评分数据

设计来源图例 · 照抄 vs 自研

本方向的价值全部押在这一页上：哪些直接照抄 freellm（省下设计决策）、哪些必须自己造（freellm 给不了）。 结论沿 U1 §5.3 —— 设计决策 ≈ 95% 可抄，代码 ≈ 10% 可抄（唯一可逐行复制的是 lib/table-sort.ts）。 页内 F 标记照抄项、O 标记自研项，可用工具条开关。

F照抄 freellm（token / 组件 / 交互契约）

  • 中性色板去彩度：bg/card/muted/border 全部 chroma=0；暗色 border = 纯白 10%，不是我们的蓝灰
  • 主色 = 近白（暗）/ 近黑（亮）：品牌蓝不再当主按钮与导航激活色
  • 字号刻度：正文/表体 12–14、标签 11、微徽章 10、统计值 20、页面标题 24
  • 全局 tnum 等宽数字：body 级，替掉我们逐处 .num 的漏标
  • 圆角刻度：卡片 24 / 表格容器 16 / 控件 8–12 / 徽章与进度条 999
  • 不用阴影分层：靠 border + bg-card；去掉现有 card hover 阴影
  • 间距 4px 基数：卡片 padding 16–20、卡片间距 16、栅格 gap 12
  • 排序三态 + 空值双向排最后 + 按表持久化（lib/table-sort.ts 可逐行翻译）
  • AxisBar 轴条 与 AxisNoData 虚线空条 + 「无数据」诚实占位
  • 骨架屏与真实行同形同数量（避免 reflow）
  • 带动作的空状态（「没有下一步的空态是死路」）
  • Panel 卡片头（标题 + 右侧 actions 槽 + 分隔线）
  • 分段控件用 aria-selected 而不是自定义 class 切换
  • 「排序只覆盖已加载行」显式提示

O我们自己的（freellm 没有，或语义不同）

  • 状态语义三档令牌 --s-ok/--s-warn/--s-bad：freellm 把状态色硬编码在组件里，我们令牌化
  • 节点评分列：freellm 是「模型三轴 + 总分」；我们的评分语义是出口可用性，且必须带样本量
  • 成功率与样本量同格 96.4% (3.2K)：freellm 的样本量是独立列，看不出「52% 只有 240 个样本」
  • 「未测量」独立分组 + 恒排末尾：freellm 只把 0 样本降级，不分组
  • 行内展开下钻（<tr class="row-detail">）：freellm 是独立路由页，我们不动导航
  • C-5 节点层告警横幅：没有任何对应物，是本项目专属的整层故障面
  • 失败构成 + 直连三类细分：我们特有的口径（闸门/连接/429/403/5xx/其它）
  • 列宽稳定：<colgroup> + table-layout:fixed；freellm 靠 Tailwind 表格默认值
  • 粘性表头：freellm 没做（它的表格外层是 overflow-x-auto）
  • 保留左侧栏 + 5 分区导航：不学 freellm 的顶部横条（U1 §7.8）
  • 保留 CJK 系统字体栈：Geist 11 个 woff2 全是 Latin，中文零收益（U1 §7.3）
  • 保留 ECharts 与现有 onclick 事件模型：CSP/React/构建链物理上搬不进 go:embed 单文件

明确不抄（✗ · 附理由）

  • React / Vite / Tailwind 构建链 —— 产物 1.68 MB JS + 102 KB CSS，且 discev_test.go:29 依赖「前端是文本资产」这个契约
  • CSP script-src-attr 'none' —— 我们有 75 处 onclick；改事件模型是另一件独立的事（U1 §7.1）
  • 自托管 Geist 字体 —— 无 CJK 字形，只增体积
  • 60 个 locale 的 i18n —— 比我们整个面板大 30 倍
  • 顶部横条导航 / 多产品面 —— 我们是单一用途本地代理面板
  • 后台标签页不轮询（refetchIntervalInBackground:false）—— 运维台把面板挂在后台当监控，这条会看出 30 秒前的状态（U1 §7.7）
  • 关键信息只放 hover tooltip —— 触屏直接丢信息；本原型的解释都同时出现在行内展开区（U1 §7.6）
  • 三轴强行凑齐 —— 后端没给的维度不画条，宁可只放一列评分（U1 §7.5）
