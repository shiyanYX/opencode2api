### 1.1 blip：失败只压分母

旧逻辑 `EffS += w*(1 - weight*0.2)`，把一次满失败折成 0.8 个成功。新逻辑：

```go
if blip {
    st.EffN += w * scoringBlipFactor // 0.2
    st.BlipFails++
} else {
    st.EffN += w
    st.EffS += w * (1.0 - oc.weight)
}
```

- 满失败在 blip 内：`EffN += 0.2w`、`EffS += 0`。
- 半权失败（5xx/stream）在 blip 内同样只压分母，不给分子。
- 这是本次分数下降的主因（212 节点里 172 个下降，中位数 −0.6，最大 −38.2）。

### 1.2 探测恢复

```go
func probePenalty(lastProbeAt, lastProbeFailAt, now time.Time) float64 {
    if lastProbeFailAt.IsZero() || lastProbeAt.After(lastProbeFailAt) { return 1.0 }
    elapsed := now.Sub(lastProbeFailAt)
    v := 0.4 + 0.6*elapsed.Seconds()/scoringProbeFailRamp.Seconds()
    if v > 1 { v = 1 }
    return v
}
```

- `probe` 分项 = 原新鲜度分 × `probePenalty`。
- 65 分封顶条件增加 `now - LastProbeFailAt < 30min`。
- `observeProbe` 连续 2 次成功时 `ProbeFailTimes = nil`。
- 参数：`scoringProbeFailRamp = 2h`、`scoringProbeCapWindow = 30min`。

### 1.3 403：池级可回溯，单订阅仍归节点

- 订阅键 = 节点名 `::` 前缀（`scoringSubOf`，无前缀退回节点名）。
- **逐条账本** `contribs403` 保留窗口内每一条已计入质量的 403：`FP / Sub / At / Weight（已乘 blip 系数）/ Blip / Historical`。
- 每条记录先扫描本记录内所有 `http 403` 的订阅，再叠加 `sub403` 中 10 分钟窗口内的订阅。
- 不同订阅数 ≥ `scoring403PoolSubs`(2) ⇒ 形态级：
  - `revertPool403Locked` 回溯窗口内所有已计入贡献：`EffN -= Weight×衰减`、`Attempts--`、`Fail.Cred--`、`BlipFails--`，并给对应节点 `Pool403++`；
  - 当前记录的所有 403 不再计入质量；
  - 设置 `pool403ActiveUntil = ts + 10min`，期间后续 403 直接视为形态级（滑动续期），不再需要第二个订阅字面出现。
- 单订阅：`Attempts++`、`Fail.Cred++`、`EffN += w`（blip 内 `0.2w`）、`EffS += 0`，并写入账本供后续回溯。
- `401/410/426` 仍走原 cred 逻辑；`403 FreeTierError` 仍走 quota（不参与本判定）。

### 1.4 正交字段

| 字段 | 语义 |
| --- | --- |
| `reach` | 探测可达性 0–1（探测分项 × 恢复斜坡） |
| `latency_score` | 延迟分项 0–1（原内部 `LatencyComponent` 导出） |
| `quota_state` | `ok` / `cooling`（exhausted ⇒ cooling） |
| `last_ok_age_s` | 距最近真实成功的秒数；无成功 = `-1` |
| `auto_eligible` | `state not in (dead, exhausted) && score>=70 && EffN>=20`，从 `json:"-"` 改为输出 |

**`sample_size` vs `effective_sample`**：`sample_size` = `Attempts`，是**当前计入质量的尝试数**；形态级 403 回溯后可以降到 0。`effective_sample` = 衰减后的 `EffN`，是加权样本量（blip 只算 0.2、7 天半衰期、403 回溯都会改变它），不是事件条数。面板/下游不要把两者当同一个数，也不要用 `sample_size==0` 推断「从未尝试」。

## 6. 已知限制 / 未决风险

1. **全量测试**：见 §4。若仍有 `TestIP4RV*` 之外的失败，均为仓库内本地 `zz_*` 验证文件的历史问题，与本任务无关、未修改。`TestIP4RVLiveServedDrift`/`TestIP4RVDocsDrift` 按 Lead 要求用 `-skip 'TestIP4RV'` 排除。
2. **旧参考对账**：旧 `scores.json` 来自旧公式，只有 4 个零样本节点可精确对账；非零样本公式对账已由 `TestScoringFormulaParityNonZeroSample` 补上（两组手算期望，误差 ≤0.1），全量独立复算由 T4 负责。T4 不要再用旧参考分。
3. **旧 blip 证据的区间**：`state.blip_fails` 是生命周期累计，10-20 前的逐条证据不可得。本表对窗口外按最大权重 0.563 扣除，得到 **严格下界**；真实 after 可能更高。日本02/香港01/新加坡原生/日本原生/台湾01 的阈值结论不受影响（直接重放 41.0/41.1 与下界 43.4/43.7 都同向）。
